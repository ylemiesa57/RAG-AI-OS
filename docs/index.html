RAG-AI-OS

A LightRAG operating system built for verification.

Local LLMs, multilingual embeddings, and graph-aware retrieval—containerized for reproducible, inspectable document intelligence.

Open repository Get started

System

One stack for retrieval you can trust.

RAG-AI-OS wraps Kotaemon, LightRAG, and GPU-accelerated llama.cpp into a portable environment with dynamic ports, PDF viewing, and folder-based knowledge sync.

Stack

Built for local power and clear provenance.

  • LightRAG Graph-based retrieval with entity-aware indexing and syncable document folders.
  • Local inference CUDA-ready llama.cpp servers for generation and multilingual E5 embeddings.
  • Verification posture Source-grounded answers, container parity, and explicit testing plans for every layer.

Start

Launch the full stack in one command.

./launch_rag_app.sh

Then open the Gradio UI (default http://localhost:7860), upload documents, and query with graph-enhanced retrieval.
