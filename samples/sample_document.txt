# Sample Document for RAG Testing

## Introduction
This is a sample document to test the RAG (Retrieval-Augmented Generation) system functionality.

## Key Features
- Document processing and indexing
- Semantic search capabilities
- Question answering with context
- Multilingual support

## Technical Details
The system uses:
- Gemma 3 27B IT model for text generation
- Multilingual E5 embedding model for semantic search
- Advanced document processing pipeline
- Real-time question answering

2. Ask questions about the content
3. Get accurate answers with source citations
4. Explore the knowledge base interactively
